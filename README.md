# 🤖 Telegram TeamSpeak Manager Bot

یک ربات تلگرامی حرفه‌ای برای مدیریت کامل سرور **TeamSpeak / TeaSpeak**  
با قابلیت کنترل کاربران، مدیریت سرور، ارسال پیام، بن، کیک و مانیتورینگ آنلاین — همه از داخل تلگرام.

---

## ✨ Features | امکانات

✅ نمایش کاربران آنلاین  
✅ ارسال پیام خصوصی به کاربران TS  
✅ Poke کاربران  
✅ Kick (سرور / چنل)  
✅ Ban موقت و دائم  
✅ مدیریت Server Groups  
✅ Verify کاربران با افزودن گروه  
✅ مشاهده مشخصات کاربران  
✅ دریافت نوتیفیکیشن اتصال کاربران  
✅ پنل مدیریت در تلگرام  
✅ سیستم سطح دسترسی ادمین  
✅ دیتابیس SQLite  
✅ کاملاً Async و سریع  
✅ سازگار با **aiogram v3**

---

## 🧠 How It Works

این ربات از طریق **ServerQuery** به سرور TeamSpeak متصل می‌شود و تمام عملیات مدیریتی را انجام می‌دهد.

⚠️ نکته مهم:
> برای عملکرد صحیح ربات، باید **ServerQuery روی سرور فعال باشد**  
> و IP سروری که ربات روی آن اجرا می‌شود در لیست مجاز (Whitelist) قرار داشته باشد.
