# 🤖 Telegram TeamSpeak Manager Bot

ربات تلگرامی حرفه‌ای برای مدیریت کامل **TeamSpeak / TeaSpeak Server**  
مدیریت کاربران، پیام، بن، گروه‌ها و مانیتورینگ آنلاین — مستقیم از تلگرام 🚀

---

## ✨ امکانات

✅ نمایش کاربران آنلاین  
✅ ارسال پیام خصوصی  
✅ Poke کاربران  
✅ Kick (سرور / چنل)  
✅ Ban موقت و دائم  
✅ مدیریت Server Group  
✅ Verify کاربران  
✅ نمایش اطلاعات کلاینت  
✅ نوتیفیکیشن اتصال کاربران  
✅ پنل مدیریت تلگرام  
✅ دیتابیس SQLite  
✅ Async و سریع  
✅ سازگار با aiogram v3  

---

## 🧠 نحوه عملکرد

ربات از طریق **ServerQuery** به TeamSpeak متصل می‌شود.

⚠️ توجه مهم:
> سرور TeamSpeak باید اجازه اتصال ServerQuery به IP ربات را بدهد.  
> در غیر این صورت ربات اجرا می‌شود ولی وصل نخواهد شد.
